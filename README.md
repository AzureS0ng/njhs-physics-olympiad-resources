## 关于仓库

我们创建这个 GitHub 仓库，是希望把散落在各届物竞生手中的资料、经验与提醒集中存放起来：一方面便于查看和检索，另一方面也便于协作维护，尽量避免因为人员毕业、设备更换或聊天记录遗失而造成资源丢失。此后，物竞教室的相关资源可以逐步整理进仓库中，形成一个可传承、可更新、可讨论的资料库。当文字不再冰冷，当经验能够透过屏幕传递给后来者，我们便足以自慰了。

欢迎各位南菁物竞生共同维护！如果你愿意参与整理、纠错、补充或分享资料，可以将你的 GitHub 注册邮箱发送至320592927@qq.com，以便添加为 Collaborators。

感谢你的阅读，祝你在物竞道路上顺利！

## 仓库内容与定位

本仓库主要用于存放和整理南菁高中物理竞赛相关的学习资源与经验材料，仅允许上传版权属于南菁高中物竞教室或物竞生个人的文件。

本仓库是物竞教室的资料整理与交流平台，并非学校官方发布渠道。仓库中的内容仅供学习交流使用。
